# Maker-KK Tap

## How do I install these formulae?

`brew install maker-kk/tap/<formula>`

Or `brew tap maker-kk/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "maker-kk/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
